# Notepad++ Color Picker

原生 Win32 Notepad++ 外掛，提供文件中 HTML 十六進位色碼的懸浮色塊預覽與點擊選色回填。

A native Win32 Notepad++ plugin that provides hover previews of HTML hexadecimal color codes in documents and lets users click to select a color and insert it back into the code.

當滑鼠移至色號上，可即時預覽顏色

Hover over a color code to preview its color in real time.
